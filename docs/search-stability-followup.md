# 搜索与扫描稳定性调整

搜索固定16并发、默认全部启用可搜索源，移除并发和范围选择。增加最多20条持久化搜索历史，支持重搜、删除和清空，跨页面共享写队列。

设备日志确认第三方DexNative.getSpider的CallObjectMethod空对象导致ART SIGABRT。在插件初始化之前检查已知native ABI并拒绝该类不兼容插件（INVALID_SOURCE），并非修复这些插件的兼容性。普通DEX仍允许加载；其他native故障仍需进程隔离。

后台插件初始化/首页/分类/搜索/直播本地请求默认取消插件对话框，仅detail/play/resolve同步作用域允许；插件另起线程不继承许可。不移除登录或认证机制。

封面增加相对及协议相对URL、URL后缀请求头和httpHeaders支持；通用Cookie/Authorization不透传。源未提供或失效图片仍使用占位，不承诺全部找回。

扫描显示全部发现节点及失败状态，取消100子节点显示截断，保留网络节点/超时/私网保护。修复内置种子被提前去重跳过、取消后重扫串扰和慢流总deadline。

本机Dart语法/格式检查通过；完整Flutter、Android及设备验收以CI和实际记录为准。
